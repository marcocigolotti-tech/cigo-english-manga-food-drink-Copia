# CIGO English Manga – Food & Drink

Web app statica bilingue per imparare a ordinare cibo e bevande in inglese.

## Pubblicazione su GitHub Pages
1. Crea un repository pubblico (es. `cigo-english-manga`).
2. Carica `index.html` nella radice del repository.
3. Apri **Settings → Pages**, seleziona **Deploy from a branch**, branch **main** e cartella **/(root)**, poi salva.
4. Apri l'indirizzo GitHub Pages mostrato da GitHub.

## Funzioni
- Dialogo inglese/italiano, lettura per battuta e lettura completa.
- Sintesi vocale tramite Web Speech API del browser, selezione lingua e velocità, arresto.
- Vocabolario bilingue con ascolto.
- 12 esercizi, correzione e spiegazioni in entrambe le lingue.
- Modalità calma, testo ingrandibile, design responsive.

La sintesi vocale dipende dalle voci e dal supporto Web Speech API del browser/dispositivo. Su alcuni dispositivi le voci devono essere installate nelle impostazioni di sistema. Non sono necessari account, servizi esterni o raccolta dati.
